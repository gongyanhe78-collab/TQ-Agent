## 4. 结果解读

1. 首位命中 50.00%、前三命中 66.67%、证据命中率 75.00%，说明「宽召回 + qwen3-rerank 重排」有效。
2. 路由准确率 45.00% 主要来自路由契约差异：当前生产规则把库内统计和列举问题交给主 RAG，
   而黄金数据集按早期契约期望 `multidim_search`。
3. 必含事实覆盖率偏低，部分原因是数据集把行为期望写进了 `required_facts`，
   例如「应同时覆盖6月和7月」，这类文本不会逐字出现在回答中。
4. 引用支持率 100%、违规断言 0，说明回答没有编造检索证据之外的引用。
5. 本次运行中意图模型出现较多超时并回退到确定性规则，属于并发下的服务稳定性问题，
   后续可用更低并发或更长超时复测。
