# 2026-08-20 相似个例匹配问题修复记录

## 一、问题一：综合研判提示被强制截断

### 现象

页面中的匹配理由、参考经验或预报建议出现“资料，核”“范围收”等半句话。该问题不是前端 CSS 截断，而是后端在模型结果清洗阶段按固定字数直接裁剪了字符串。

### 原因与风险

综合研判提示词原先要求 `suggested_action` 不超过 45 字，清洗函数也把 45 字当作硬上限；`focus_object` 和 `possible_bias` 同样存在固定上限。模型输出稍长时，`normalize_business_text()` 会在字符中间截断并补句号，导致动作对象、调整对象或句尾信息丢失，业务人员可能误解建议。

### 解决措施

1. 在 `text_quality.py` 增加 `normalize_soft_text()`：目标长度只作为模型排版建议，完整句可以在安全上限内略微超出。
2. 优先在句号、问号、感叹号、分号等完整句边界收束；没有完整句边界时才在逗号等分句边界收束；完全没有边界的异常长文本使用省略号，不伪造句号。
3. 综合研判提示词改为“目标控制在约 30/35/45 字”，并明确不得为凑字数省略动作对象或句尾。
4. `focus_object`、`possible_bias`、`suggested_action` 使用软上限和独立安全上限；内部结构化字段、证据关联和整体业务流程不变。
5. 修复句末标点在前置清洗阶段被去除的问题，确保模型已经返回完整句时仍能识别句子边界。

## 二、问题二：跨灾种术语合理性误判

### 现象

沙尘过程的综合研判中，“能见度演变”“最大阵风”等业务上合理的伴随指标被判定为术语违规并触发修复；另一方面，某些真正不适用于当前过程的术语（例如没有雪相态证据的暴雨场景中的“冷垫”）又需要继续拦截。

### 原因与风险

原校验逻辑将所有当前配置之外的 `foreign_terms` 按逐字包含规则直接判为违规。不同灾种之间存在大量共享观测量、变化关系和伴随指标，严格的配置词表会误杀合理表述，触发不必要的二次模型调用，严重时还会把有效提示中性化；如果为了避免误杀而完全取消校验，则会重新引入跨灾种模板污染。

### 解决措施

1. 将术语判断调整为分级思路：有原文/证据逐字支持的术语直接通过；与当前配置具有相同物理主体的变化词、量级词和观测词作为合理辅助指标通过；只有无证据且物理主体与当前配置明显脱离的术语才进入定向修复。
2. 增加通用语义主体归并函数，覆盖能见度、风场、降水、水汽、温度、环流、对流、沙尘、雪相态和持续时长等少量可迁移主体，不为每个灾种穷举核心指标或禁词。
3. 将“当前灾种配置术语”和“通用证据主题”分开计算。当前原文明确出现的词可保留；仅出现在历史证据中的词还必须与当前灾种共享物理主体，避免历史证据自身携带的“冷垫”等词反向污染暴雨综合研判。
4. 保留原有“一次定向修复、二次校验、失败时中性化”的安全链路，因此明显跨灾种概念仍不会直接展示。
5. 修复提示词强调：合理的伴随指标不要删除；只改写明显冲突或无依据的强断言；保持 JSON 结构、case_id、chunk_id 和事实证据不变。
